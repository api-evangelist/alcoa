# Alcoa Corporation

> Alcoa Corporation is a global producer of bauxite, alumina and aluminum, founded in 1888 and
> headquartered in Pittsburgh, Pennsylvania. It operates mines, refineries and smelters in
> Australia, Brazil, Canada, Iceland, Norway, Spain and the United States, and supplies
> primary aluminum, alumina and cast products to the automotive, aerospace, packaging,
> construction and industrial markets.

- No GitHub organization `alcoa`; no first-party package on npm, PyPI, RubyGems, crates.io,
  NuGet, Maven Central or Packagist

`https://api.alcoa.com` does resolve and is a live Microsoft Azure API Management gateway
(`api.alcoa.com.trafficmanager.net` -> `app-prod-noa-itas-apim-appgw-ip.eastus.cloudapp.azure.com`).
It answers `401 Access denied due to missing subscription key` on `/echo/resource` and a JSON
`404 Resource not found` on every other path probed, including all discovery paths. It is an
internal / partner integration gateway, not a published product API: there is no reference,
no spec and no way to obtain a subscription key from a public page.
